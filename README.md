# CZL 单证

CZL Express 出品的免费外贸单证工具（Windows / macOS）：一票货录入一次，按需生成商业发票、形式发票、装箱单、出口报关单与申报要素，支持中英双语、PDF 与 Excel 导出，常用收发件人与品名申报要素可存成库反复调用。数据只存在本机。

本产品原名「CZL 发票」，旧版客户端可直接在线升级，数据与登录不受影响。

本仓库只用于编译和发布安装包，程序通过这里的 Release 在线更新。

- 产品介绍：https://www.czl.net/cn/tradedocs
- 下载安装包：https://drive.czl.net/@s/ctr ，或本仓库 [Releases](../../releases/latest)
- 问题反馈：https://www.sunai.net/t/topic/1494
- 邮件：support@czl.net

## 安装

- **Windows 10 / 11**：下载 `CZLTradeDocs-Setup-<版本>.exe` 运行即可，按当前用户安装，不需要管理员权限。
- **macOS 10.13 及以上（Intel 与 Apple 芯片通用）**：下载 `CZLTradeDocs-<版本>-macos.dmg`，打开后把「CZL 单证」拖进「应用程序」。
  安装包未经 Apple 公证，首次打开会提示无法验证开发者：到「系统设置 → 隐私与安全性」底部点「仍要打开」，之后不再询问。在线更新不需要重复这一步。
