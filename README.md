# CZL 单证

CZL Express 出品的免费 Windows 外贸单证工具：一票货录入一次，按需生成商业发票、形式发票、装箱单、出口报关单与申报要素，支持中英双语、PDF 与 Excel 导出，常用收发件人与品名申报要素可存成库反复调用。数据只存在本机。

本产品原名「CZL 发票」，旧版客户端可直接在线升级，数据与登录不受影响。

本仓库只用于编译和发布安装包，程序通过这里的 Release 在线更新。
