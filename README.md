# CZL 发票

CZL Express 出品的免费 Windows 报关单据工具：一票货录入一次，同时生成商业发票、形式发票和装箱单，支持中英双语、PDF 与 Excel 导出。数据只存在本机。

本仓库只用于发布安装包，程序通过这里的 Release 在线更新。
